# 05. 実装上の判断・制約・今後

## 実装上の判断
それぞれ「そうしなかった場合に何が起きるか」とセットで書きます。

### 固定ステップループはタイマに依存させない
ブラウザのタイマは最小間隔も精度も保証されません。
そこで `Stopwatch` で「何 ms 経ったか」を測り、必要なステップ数だけまとめて進めます
(`src/Ip.Client/Services/PlantRunner.cs`)。

長時間止まっていた場合 (タブ非アクティブ等) は実時間に追いつこうとせず、
0.2 秒を超えるぶんは捨てて「時間スリップ」として数えます。
追いつこうとすると、復帰の瞬間に数千ステップを一気に回してフリーズします。

### Hub のメソッドは受信を Channel に積むだけ
制御計算は接続ごとの単一ループで行います (`src/Ip.Server/Sessions/ControllerSession.cs`)。
Hub の呼び出しスレッドで重い処理をすると、**他の接続の受信まで遅れる**ためです。
この直列化があるので `ControllerCore` はロックを持ちません。

### 描画は JS 側の rAF に逃がす
.NET からは 50Hz で状態を push するだけです (`src/Ip.Client/wwwroot/js/sim-view.js`)。
描画が重くなっても制御ループもプラントの積分周期も乱れません。
.NET 側で描画すると、描画コストが積分周期に直結します。

### 通信路エミュレーションは送信側のキュー
SignalR は TCP 上で動くのでパケットは落ちません。
損失は**再送による遅延スパイク**として現れるため、+150ms の注入と追い越し禁止で模擬しています。
「ランダムにメッセージを捨てる」実装は、TCP の上では起こりえない事象を模擬してしまいます。

### `SharedArrayBuffer` / `WasmEnableThreads` は使わない
必要なら `Sil:CrossOriginIsolation` を `true` にすると COOP/COEP ヘッダを配信できます。
既定で有効にしないのは、クロスオリジン分離が外部リソースの読み込みを壊すためです。

### three.js は同梱する
CDN から引くと、遮断された環境で 3D ビューが**無言で消え**、CSP も緩める必要があります
(`src/Ip.Client/wwwroot/lib/three/README.md`)。

### 受信した double は必ず有限性を検査する
`Math.Clamp` は Infinity を境界へ落としますが **NaN は素通しします**。
1 つ混ざると以降の比較がすべて false になり、
「ウォッチドッグが永久に鳴らない」形の静かな故障になります (`Sanitize.Finite`)。
詳細は [02-protocol.md](02-protocol.md)。

### 制御の判断に 2 台の時計の差を持ち込まない
開始時刻の判定・速度推定・E2E 遅延はすべてプラント時計だけで閉じており、
クロック同期の推定は「上り遅延」の**表示にしか**使いません。
制御に持ち込むと、時計ズレが制御量に化けます。

### 静的アセットは `MapStaticAssets` で配信する
`_framework/*` は指紋付きで配信されるため、ファイル名で引く `UseStaticFiles` では解決できません。
また Blazor WASM クライアントのアセットは既定では Development でしか合成されないので、
`UseStaticWebAssets()` を明示的に呼んでいます (publish 済み構成では何も起きません)。

## 既知の制約
- **設計計算が制御ループと同じスレッドで走る。**
  コントローラの再設計 (離散 LQR + 遅延余裕) は結果をキャッシュし、UI 側でもデバウンスしているため
  通常は表に出ませんが、**未知の組合せを初めて要求すると数十 ms 制御ループが止まります**。
  根本的には設計計算を別タスクに追い出すべきです。
- **タイマ粒度。** `Task.Delay(1)` の実測周期は OS のタイマ粒度に丸められて 4ms 前後です。
  帰還 1 本ごとの制御計算はイベント駆動なので影響しませんが、
  **ウォッチドッグと遅延線の解像度はこの粒度**になります。
- **認証がない。** 1 接続 = 独立した 1 シミュレーションで他の接続の状態には触れられませんが、
  `compose.yaml` はループバックにのみ公開しています。公開する場合は認証が要ります。
