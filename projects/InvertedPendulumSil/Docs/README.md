## このプロジェクトが答えようとしている問い
安定化ループ (倒立を維持する高速な閉ループ) を**バックエンドに置く**設計は、
通信遅延のもとでどこまで成立するのか。

倒立振子は倒立点に不安定極を持つため、ループ遅延に対する許容量が有限です。
本プロジェクトはその許容量を理論 (線形化 + 離散化 + 二分探索) と
実測 (仮想時間の結合テスト・ブラウザ結合テスト) の両方で求め、
数値で答えを出すことを目的にしています。結論は [03-delay-margin.md](03-delay-margin.md) にあります。
