## 用語
| 用語 | 意味 |
| --- | --- |
| 部品 (component) | エミュレータを構成する最小単位。1 つの WASM コンポーネント (または組み込み型)。入力ポート / 出力ポート / パラメータを持ち、`step(dt)` で進む |
| 構成情報 (manifest) | どの部品をどのパラメータで何個置き、どう配線し、どの周期で回すかを記した JSON。サーバが版管理し署名する |
| 配線 (wire) | ある部品の出力ポートから別の部品の入力ポートへの接続。ホストが毎ステップ値を転記する |
| スケジューラ | 仮想時間を固定ステップで進め、部品を決められた順に `step` する単一スレッドのループ (エンジン内) |
| エンジン | クライアントの Rust プロセス `ipemu-engine`。bootstrap・検証・組み立て・スケジューラ・capability の実施・IPC を担う |
| シェル | クライアントの UI プロセス (Electron)。描画と操作、同意ダイアログ。状態は持たない |
| capability | 部品 / ファームウェアが使う OS 資源 (TCP・ファイル・時計など) の許可単位。manifest で宣言し、承認・同意を経て WASI として付与する |
| 仮想 MCU (`cpu-virtual`) | 組み込み部品の 1 つ。周辺 (エンコーダ計数・PWM・GPIO・UART) をポートとして持ち、注入されたファームウェアを周期的に呼ぶ |
| ファームウェア (firmware) | 仮想 MCU の中で走る制御プログラム。HAL だけに依存する C / C++ / Rust ソースを wasm (配布) とネイティブ共有ライブラリ (デバッグ) にビルドする |
| HAL | ファームウェアから見た周辺アクセス API。WIT では `ip:emu/hal`、C では `abi/ip_hal.h`。wasm では import、ネイティブでは関数テーブルで提供される |
| アーティファクト | サーバが配信するバイナリ (部品 WASM、ファームウェア WASM、UI バンドル)。sha256 で内容を同定する |
